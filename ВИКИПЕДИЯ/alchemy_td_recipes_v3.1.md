## Свои рецепты v2 (сохранены)

| Рецепт | Причина отклонения от канона |
|---|---|
| Вода + Давление = Холод | канонный холод = дождь + человек, идёт через жизнь |
| Вода + Дым = Кислота | канонной кислоты нет, есть кислотный дождь = облако + дым |
| Энергия + Металл = Электричество | канонное = солнце + солнечная батарея, идёт через космос |

| Рецепт | Результат | Причина |
|---|---|---|
| Земля + Грунт = Суша | Суша | в v2 было Суша+Суша, не вписывалось в паттерн спин |

| Растение + Воздух = Кислород | Кислород | в v2 было Растение+Энергия, изменено для логики |

## Принятые решения

- **Один рецепт на один элемент.** Множественные исходы не допускаются.
- **Гранит выброшен.** Камень уже есть, второй камень не нужен.
- **Бумага удалена.** Тупик без боевой роли.
- **Тупики допустимы.** Стекло, Лёд, Обсидиан, Электричество, Антиматерия ни к чему не ведут — это нормально.
- **Провод удалён.** Металл + Электричество — это уже следующий тир, а дерево заканчивается на четвёртом.
- **Ничего не удаляем.** Пруд, Континент, Суша, Лужа, Кирпич, Стена, Глина, Гора, Океан, Ураган остаются, несмотря на то что боевой роли у них может не быть.
- **Биология допустима.** Растение, Дерево, Жизнь, Кислород, Мыло допускаются, если работают механически.
- **Чистокровные спины — единственный источник паттерна крафта.**

## Итог

Дерево содержит 72 элемента (4 базовых + 68 производных) и 68 рецептов. Списки выше — полные, единственный источник правды по составу дерева. Своих рецептов 8, всё остальное канон или адаптация канона.
