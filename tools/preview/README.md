# Браузерный 3D-просмотрщик

Это отдельное WebGL-приложение для браузера. Оно загружает настоящий GLB жука `standard_beetle.glb` из ресурсов проекта, показывает каталог 71 элемента и 8 профилей останков и проигрывает для выбранного элемента отдельную 3D-анимацию.

> Модель — настоящий файл проекта. Снаряд и эффекты останков в браузере — визуальная симуляция на Three.js, а не исполнение Roblox/Luau и не точная копия физики Roblox. Серверные эффекты при смерти (зоны, урон по области, растения, барьеры) здесь не запускаются.

## Локальный запуск

```sh
cd tools/preview
npm install
npm run dev
```

Затем открыть адрес, указанный Vite (по умолчанию `http://localhost:4173`). Vite слушает `0.0.0.0`, поэтому страница работает и через Arena Live Preview.

## Управление

- Клик по элементу начинает демонстрацию; «Все» и «Уникальные» переключают 71 запись и 8 профилей.
- ЛКМ по сцене — вращение камеры, колесо — приближение/отдаление.
- Space — повтор или пауза; стрелки влево/вправо — переключение элемента.
- Для «Хрупкого трупа» после попадания доступна кнопка «Расколоть».

`data/elements.json` — браузерный снимок русских названий, цветов, профилей и меток элементов из `Elements.luau`. Модель лежит в `public/models/standard_beetle.glb` (копия `Модели/Жуки/standard_beetle.glb`).
