# 3D-просмотрщик смерти от снаряда

`DeathShowcase3D.client.luau` — отдельный локальный инструмент для **Roblox Studio**. Это не HTML-макет: он строит настоящий `Enemies.Normal` через `EnemyModel.Build`, запускает настоящие `CorpseFX.Leave` и игровые ветки `CorpseRemains`, а для хрупкого трупа вызывает `CorpseFX.Shatter`.

Инструмент лежит вне `src/` и Rojo-маппинга; игровые модули и `place/game.rbxl` не меняются.

## Запуск

1. Открой `place/game.rbxl` в Roblox Studio и нажми **Play**.
2. В Explorer открой `StarterPlayer > StarterPlayerScripts`.
3. Создай там **LocalScript** с именем `DeathShowcase3D`.
4. Открой `DeathShowcase3D.client.luau`, скопируй весь код в Source нового LocalScript.
5. Во время Play нажми **Ctrl+Shift+B**. Эта же комбинация или кнопка «Закрыть» вернёт обычный вид игры.

## Управление

- Нажми на элемент в списке: его снаряд сразу полетит в модель.
- **Все · 71** — каталог всех элементов; **Уникальные · 8** — по одному представителю на каждый профиль останков.
- «Запустить смерть» повторяет выбранную демонстрацию; кнопки ‹ и › или стрелки ← и → переключают элемент.
- Для профиля «Хрупкий труп» после попадания станет доступна кнопка «Расколоть хрупкий труп».
- Зажми **правую кнопку мыши** и двигай мышь, чтобы вращать камеру; колесо над центральной сценой меняет масштаб.
- **Ctrl+Shift+B** открывает/закрывает просмотрщик; **Esc** закрывает его.

## Изоляция

Просмотрщик запускается только при `RunService:IsStudio()`. Сцена создаётся локально на клиенте, далеко над игровой картой, а камера и видимость игровых интерфейсов восстанавливаются при закрытии. Для стенда используется копия `CorpseFX` с отдельным списком трупов; это не даёт просмотру каталога вытеснять обычные игровые трупы. `Elements` и `Enemies` только читаются; серверные remotes и серверные решения не вызываются.

Снаряд стенда — простая 3D-визуализация попадания; сама модель жука, поза смерти, физика останков и ветки `CorpseRemains` берутся из игровых модулей. Серверные последействия элементов (например, зоны, урон по области, растения или барьеры) стенд не запускает: они зависят от серверной волны и не должны изменять реальную игру. Проверить работу можно только в Roblox Studio: в этом окружении Studio не запускается.
